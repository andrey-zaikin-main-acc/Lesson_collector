# Lesson Collector

Lesson Collector преобразует один сохранённый раздел учебного курса в один автономный HTML-файл. Итог открывается с диска обычным браузером: рядом не нужны Python, папка `_files`, вход в учебную платформу или интернет.

Первая версия рассчитана на сохранение браузера «Веб-страница полностью», в котором учебное содержимое находится в самой странице или в локальном iframe. Рядом с исходным HTML должна находиться папка `<имя>_files` либо архив `<имя>_files.zip`.

## Что делает конвертер

- находит наиболее содержательный локальный iframe без привязки к имени `index.html`;
- переносит заголовки, абзацы, списки, таблицы, подписи и порядок элементов;
- делает сохранённые раскрывающиеся блоки видимыми без JavaScript;
- определяет тип изображений по байтам и встраивает исходные байты через data URI;
- заменяет отсутствующие изображения понятными отметками;
- удаляет скрипты, формы, обработчики событий, перенаправления, служебные атрибуты и внешние/локальные зависимости;
- превращает внешние ссылки в неактивный текст с адресом без query-параметров;
- добавляет собственные стили чтения и печати, системные шрифты и ограничительную Content Security Policy;
- создаёт JSON-отчёт с проверкой текста, изображений, зависимостей и границ сохранённого раздела.

Исходные файлы не меняются. Существующий результат не перезаписывается без `--overwrite`.

## Установка в Windows 11

1. Установите Python 3.12 или новее с [python.org](https://www.python.org/downloads/windows/). При установке включите Python Launcher (`py`).
2. Откройте PowerShell или командную строку в папке проекта.
3. Создайте окружение и установите единственную зависимость:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск двойным щелчком

Дважды щёлкните `START.bat`. Он автоматически использует `.venv`, если окружение создано по инструкции выше, иначе запускает системный Python 3.12. Откроется стандартное окно выбора исходного HTML, затем окно выбора папки результата. При отмене второго окна результат попадёт в папку `converted` рядом с исходным HTML.

## Запуск из командной строки

```bat
.venv\Scripts\python.exe lesson_collector.py "C:\Курс\Урок 1.html" -o "C:\Курс\Готово"
```

Для явной замены ранее созданных файлов:

```bat
.venv\Scripts\python.exe lesson_collector.py "C:\Курс\Урок 1.html" -o "C:\Курс\Готово" --overwrite
```

Результаты:

- `<имя>_autonomous.html` — автономный документ;
- `<имя>_report.json` — отчёт о полноте и проверках.

Код возврата `0` означает, что результат создан (возможные предупреждения напечатаны и записаны в JSON), `2` — ошибка входных данных, `3` — ошибка файловой системы.

## Проверка

Автоматические тесты используют только небольшие искусственные страницы и проверяют отсутствующее изображение, PNG без расширения, кириллицу в путях, защиту от выхода из временной папки ZIP и запрет неявной перезаписи:

```bat
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

JSON-отчёт проверяет нормализованный учебный текст до и после преобразования, SHA-256 и байты встроенных изображений, а также отсутствие загружаемых внешних или локальных ресурсов. Скрипты, стили, поля `input` и добавленные поясняющие отметки перечислены как явные исключения из сравнения текста.

## Ограничения первой версии

Инструмент обрабатывает один уже сохранённый раздел за запуск. Он не входит в аккаунт, не управляет браузером и не скачивает соседние разделы. Видео, аудио, задания, canvas и вложенные интерактивные страницы становятся статическими отметками и попадают в отчёт. Эффекты интерфейса и оригинальные веб-шрифты заменяются спокойным статическим оформлением. Если в сохранении есть лишь кнопка перехода к другому разделу, конвертер сообщает об этом и не выдумывает отсутствующее содержимое.
